Le trajet

Trois étapes, rien de plus

L'outil tient dans une page. Pas de serveur, pas de compte, pas de base de données — ton navigateur parle directement à l'API d'Anthropic.

01 — capture

La page est photographiée

L'URL passe par thum.io, qui renvoie une capture large de 1280 px. C'est cette image, pas le HTML d'origine, qui part chez Claude.

02 — lecture

Claude regarde et réécrit

claude-opus-4-6 reçoit l'image en vision et rend du HTML pur — <style> inclus, aucune explication autour.

03 — récupération

Tu télécharges le fichier

Un aperçu s'affiche, puis le bouton enregistre cloned-site.html. Le fichier s'ouvre seul, sans dépendance.

À savoir avant de cliquer

Ce que l'outil fait, et ce qu'il ne fait pas

Ta clé API est saisie dans la page

Website Cloner n'a pas de serveur : ta clé sk-ant-… est tapée dans le navigateur et envoyée directement à l'API d'Anthropic, via l'en-tête anthropic-dangerous-direct-browser-access. Elle n'est ni stockée ni transmise ailleurs, mais elle transite par une page que tu dois servir toi-même.

À n'utiliser qu'avec une clé que tu peux révoquer, sur une page que tu contrôles. Pour un usage partagé, il faut un relais côté serveur qui garde la clé.

C'est une reconstruction, pas un miroir

Claude travaille depuis une image : il rend ce qui se voit. Les polices exactes, les scripts, les états au survol, ce qui vit sous la ligne de flottaison ou derrière une interaction ne sont pas capturés. Le résultat est une maquette fidèle à l'œil, pas une copie du site.

Bon pour : partir d'une mise en page repérée, reproduire une structure, dégrossir une intégration. Pas pour : reprendre un site en production.
